# Electromagnetic Modeling

MATLAB projects from the course *Electromagnetic Modelling of Micro-Nano Structured Surfaces* (Université Jean Monnet, Saint-Étienne), by Joshua Dakim Solomon.

| Project | Description |
|---|---|
| [`paraxial-bpm-gaussian-beam`](paraxial-bpm-gaussian-beam/) | Free-space propagation of a 2D Gaussian beam with the paraxial Fourier split-step beam propagation method (`Gauss.m`). |
| [`bpm-photonic-nanojet`](bpm-photonic-nanojet/) | BPM simulation of a Gaussian beam focused by a thin lens, then of the photonic nanojet formed by a fused-silica microcylinder in water: validation against the exact Mie solution, numerical checks, parametric study and a core–shell design. |
